---
description: Per rep, the pipeline they hold, what they won and lost in 90 days, real cycle times, activity and overdue next steps.
---

1. Run `npm run crm -- scorecard`.
2. Read pairs, not single columns:
   - big pipeline + low activity = a pipeline of wishes,
   - wins + short cycle = the motion to copy,
   - overdue next steps > 0 = the first coaching conversation.
3. Cycle days is opened-to-won over the last year, computed from the records, not remembered.
4. One line per rep, then the single thing you would change this week.

`npm run docs -- rep-forecast` renders each rep's quarter as a one-pager for the pipeline review.
